# Hotel demo — The Palm House
Open index.html directly, or serve the Website folder with a static web server. No build or backend required.

Files: index.html (content), styles.css (design), script.js (navigation and footer year), sitemap.html (visitor sitemap).

Before publishing: replace the imaginary business name, address, email, sample rates, amenities, reviews and photos. Update Facebook and Instagram URLs and the placeholder WhatsApp number in index.html. This is an informational website only: no booking form, availability tracking, payments or guest data collection. Visitors can contact the hotel directly through its email or social links. No database or staff dashboard is needed for this version.

Images load from Unsplash and fonts from Google Fonts; internet access is required for these assets. The layout includes fallback fonts and image background colours.

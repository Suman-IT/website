# Dr. Das Nursing Home demo

A lightweight, responsive HTML/CSS/JavaScript website template for Hostinger.

## Edit the demo

1. Open `data/hospital-data.js`.
2. Replace the clearly marked placeholder values with verified information from the nursing home.
3. Update the Google Maps URL and embed URL in the same file.
4. Replace demo reviews and photo placeholders only with approved content.

The appointment form is intentionally front-end only. Connect it to an approved email/form backend before launch; it does not confirm appointments.

## Preview locally

From this folder, run any static server, for example:

```text
python -m http.server 8000
```

Then open `http://localhost:8000`. For Hostinger, upload the files and folders into `public_html`.
